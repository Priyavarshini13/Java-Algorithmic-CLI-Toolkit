# Java Algorithmic CLI Toolkit

A menu-driven command-line application built using Java 21
to demonstrate fundamental Data Structures and Algorithms.

## Features

- Linear Search
- Binary Search
- Bubble Sort
- Merge Sort
- String Reversal
- Palindrome Checking
- Time and Space Complexity Analysis
- Input Validation

## Technologies

- Java 21
- Object-Oriented Programming
- Data Structures and Algorithms
- Java Collections
- Command Line Interface

## How to Run

```bash
cd src
javac Main.java SearchAlgorithms.java SortAlgorithms.java StringAlgorithms.java
java Main
